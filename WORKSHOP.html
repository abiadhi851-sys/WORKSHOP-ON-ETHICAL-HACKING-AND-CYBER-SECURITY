ABOUT THE WORKSHOP

This workshop introduces students to ethical hacking, cyber security, and digital safety.

Date: 12th November 2026

Time: 9:00 AM - 5:00 PM

Venue: SRM TRP ENGINEERING COLLEGE, Trichy

WORKSHOP SESSIONS

Session 1: Introduction to Cyber Security

Learn about cyber threats, malware, phishing, and online safety.

Session 2: Ethical Hacking

Understand penetration testing and responsible disclosure.

Session 3: Network Security

Learn about IP addresses, ports, protocols, and firewalls.

Session 4: Practical Lab

Practice security scanning in a safe lab environment.

ETHICAL HACKING TOOLS

Kali Linux - Security testing operating system

Nmap - Network scanning tool

Wireshark - Network traffic analysis tool

Burp Suite - Web security testing tool

OWASP ZAP - Web application security tool

CYBER SECURITY LAB SETUP

Computer or laptop with 8 GB RAM

VirtualBox or VMware

Kali Linux virtual machine

Nmap and Wireshark tools

Isolated virtual network

Practice applications for security testing
